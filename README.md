# 🔥 FlameCore

> Главный управляющий модуль сервера **FlameDex**.
> Плагин для **Paper 1.20.1** (Java 17).

Защита входа администраторов через Telegram, инструменты управления сервером, конкурсы,
промокоды, косметика для админов, анонсы стримов и топ по платежам (NPC + голограмма).

---

## ⚙️ Функции

- **🛡 Защита входа админов** — при заходе админ замораживается (слепота + блокировка движений
  и действий) с **BossBar**-индикатором и тайтлом, пока владелец не подтвердит вход кнопками
  в Telegram-боте. Есть **TTL входа** (`protection.login-timeout`): если за это время не ответили —
  админ размораживается сам.
- **📨 Telegram бот** — владельцу приходят **3 кнопки**: «Впустить», «Кикнуть»,
  «Выдать доступ к панели». После «Впустить» клавиатура сжимается до кнопки выдачи панели,
  любое другое действие убирает кнопки. Админы получают уведомление в личку
  с кнопками «Впустить» / «Кикнуть».
- **⚠️ Защита опасных команд** — команды «фулл-доступа» (`/op`, `/lp …`, `* add/set/grant`,
  `whitelist off`, `stop/restart` и др.) не выполняются сразу: админу уходит подтверждение,
  владельцу — кнопка «Отклонить и забанить». По таймауту команда выполняется сама;
  отказ владельца = вечный бан. Команды **бана** подтверждения не требуют (модераторы багят игроков без задержки).
- **🚨 Кик не-админов с запрещёнными пермишенами** — если игрок не указан в `admins` (и не владелец),
  но имеет **op** или один из запрещённых пермишенов (`protection.kick-non-admin-permissions`,
  например `*`, `luckperms.*`, `group.admin`) — его кикает на входе, а владельцу в Telegram уходит алерт.
- **🎟 Промокоды** — игрок пишет в чат `/название` (например `/jonycape`) и получает награду:
  консоль выполняет команды из конфига, игроку показывается чат-сообщение + тайтл,
  вокруг взрывается фейерверк. Лимит использований настраивается **на игрока** (`promo-codes.<code>.uses`),
  все тексты и цвета — в конфиге.
- **✨ Кастомизация админов** (`flamecore.customize`) — `/flamecore customize`:
  цветное свечение персонажа (эффект **GLOW**, цвета скорборда, включая радужный),
  бессмертный попугай на плече и нимб из белых частиц над головой. Попугай сидит на плече через
  **shoulder-сущность** (`setShoulderEntityLeft`, сама сущность после этого удаляется из мира —
  без летающего мира-сущности и без следа дубликатов; пере-садка при «слетании»). Если на сервере
  установлен **TAB** (плагины скорбордов/команд конфликтуют за команды), цвет свечения передаётся
  через **PlaceholderAPI**-плейсхолдер `%flamecore_glowcolor%` (см. «Настройка под TAB» ниже).
  Тики оптимизированы (эффекты с настраиваемым периодом, чистка при выходе).
- **📺 Стримеры** (`flamecore.stream`) — `/flamecore stream <url>` анонсирует стрим на весь
  сервер (ник + ссылка из конфига) с кулдауном на игрока (`stream.cooldown`).
- **💰 Топ по платежам** (`flamecore.admin`) — `/flamecore addpayment <ник>` добавляет +1
  к счётчику игрока (шлёт сайт при покупке), данные хранятся в H2. `/flamecore paymenttop spawn`
  создаёт NPC-жителя и голограмму (DecentHolograms) с топ-5 игроков на месте; `remove` убирает,
  `clear` — полный вайп. Житель бессмертный (нельзя убить), без имени, всегда смотрит на игрока;
  голограмма висит над головой и обновляется каждые `donatetop.update-interval` минут. Точки
  спавна переживают рестарт.
- **✅ Full HTML-safe** — весь пользовательский контент (ник/IP/команда) экранируется
  перед подстановкой в `<b>`/`<code>`, никаких «сырых» тегов в чате. Поддерживаются цитаты
  `<blockquote>` в сообщениях бота.
- **📊 Управление сервером** — команда `/flamecore` (tps, mspt, system, online, worlds, player…)
  с автодополнением по Tab. Панель открывается кнопкой «Выдать доступ к панели».
- **🎁 Конкурсы** — `/giveaway create <приз> <время>` и `/giveaway join <id>`, победитель выбирается автоматически.
- **🎨 Все сообщения настраиваемые** — в игре через `messages:` (`messages.yml`), в Telegram —
  через `telegram-messages:` (`admin-guard.yml`). Поддержка HEX-цветов (`&#RRGGBB`) и многострочных
  текстов. В строках сообщений можно использовать **теги**: `[console] <команда>` (консоль выполнит
  команду, подставит `%player%`), `[sound] <ЗВУК> [громкость] [питч]` (проиграть звук игроку,
  например `[sound] LEVEL_UP 1.0 2.0`; работают и старые, и новые имена звуков — резолвер сам
  подберёт актуальный для версии), `[message] <текст>` (написать игроку). Строка без тега — обычное сообщение.
- **🗂 Разбитая конфигурация** — вместо одного огромного `config.yml` настройки лежат по файлам
  (в `config.yml` — только база данных, бот и владелец).

## 🚀 Установка

1. Положи `FlameCore-1.0.0.jar` в папку `plugins/` сервера.
2. Запусти сервер — плагин создаст конфигурацию.
3. Настрой конфиг. Он разбит по файлам (в `config.yml` — только база данных, бот и владелец):
   - `config.yml` — `database` (H2), `bot.token`, `owner.name` / `owner.telegram_id`;
   - `admin-guard.yml` — `admins` (карта `ник → ID Telegram`), `protection`
     (dangerous-commands, login/confirm-timeout, kick-non-admin-permissions) и `telegram-messages`;
   - `messages.yml` — все игровые сообщения;
   - `promo-codes.yml` — промокоды (код как ключ, `uses` на игрока, `commands`, `colors`/`fade`);
   - `customize.yml` — настройки косметики (интервалы, радиус/кол-во нимба);
   - `stream.yml` — кулдаун стримов;
   - `donatetop.yml` — топ по платежам (интервал, текст голограммы, точки спавна NPC).
4. Перезапусти сервер / `/flamecore reload`.

> **Перед первым запуском после обновления** удали старый `config.yml` из папки плагина —
> чтобы сгенерировались новые файлы, или перенеси свои настройки в новые файлы.

> **Настройка под TAB** (если установлен): TAB сам управляет командами скорборда и не даёт
> FlameCore раскрашивать свечение (цвет получается белым). Чтобы TAB и цвет работали вместе:
> 1. На сервере должен быть **PlaceholderAPI** (FlameCore подключает его автоматически,
>    в `plugin.yml` уже есть `softdepend: [PlaceholderAPI]`).
> 2. В `plugins/TAB/groups.yml` в конце `tagprefix` добавь плейсхолдер `%flamecore_glowcolor%`,
>    например:
>    ```yaml
>    _DEFAULT_:
>      tagprefix: '%luckperms_prefix%%flamecore_glowcolor%'
>    ```
>    TAB сам берёт последний цвет префикса как цвет команды → свечение раскрашивается,
>    префиксы и сортировка TAB не ломаются.

## 📌 Команды

| Команда | Описание |
|---------|----------|
| `/flamecore` | Справка по управлению сервером |
| `/flamecore tps / mspt / system / online / worlds / check` | Информация о сервере |
| `/flamecore announce <текст>` | Объявление игрокам |
| `/flamecore player <ник>` | Информация об игроке |
| `/flamecore reload` | Перезагрузка конфигурации |
| `/flamecore customize` | Меню кастомизации (свечение, попугай, нимб) — `flamecore.customize` |
| `/flamecore customize color <цвет>` | Цвет свечения (red…white, rainbow, off) |
| `/flamecore customize parrot` | Бессмертный попугай на плече |
| `/flamecore customize nimb` | Нимб из белых частиц над головой |
| `/flamecore stream <url>` | Анонс стрима на весь сервер — `flamecore.stream` |
| `/flamecore addpayment <ник>` | +1 к счётчику платежей игрока (шлёт сайт) |
| `/flamecore paymenttop spawn` | Создать NPC-жителя + голограмму топа на своём месте |
| `/flamecore paymenttop remove` | Убрать NPC + голограмму |
| `/flamecore paymenttop clear` | Полный вайп топа платежей |
| `/giveaway create <приз> <время>` | Создать конкурс |
| `/giveaway join <id>` | Участвовать в конкурсе |
| `/<название-промокода>` | Активировать промокод (например `/jonycape`) |

> Доступ к `/flamecore` даёт кнопка **«Выдать доступ к панели»** в Telegram-боте.
> `/flamecore customize` и `/flamecore stream` открыты по правам `flamecore.customize`
> и `flamecore.stream` соответственно.
